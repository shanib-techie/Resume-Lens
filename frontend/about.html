2. What is used in this project

ResumeLens compares resumes (PDF, DOCX, or a ZIP of many) with a skill list and shows a keyword match score. It is a keyword check, not a real ATS.

Backend
PythonFastAPIUvicornPyPDF2 python-docxpython-multipartzipfiledifflib
Frontend
HTML5CSS3JavaScript
How it works
  • Search from 690+ skills in 25 fields, or type your own skill.
  • The backend reads each resume and looks for every skill, including short forms and small spelling mistakes.
  • Match % = skills found / skills chosen x 100.
  • Resumes at or above your minimum match go into the download zip.
